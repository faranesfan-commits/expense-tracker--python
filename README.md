# expense-tracker--python
A personal expense tracking application built with Python.
## Features

- Add new expenses with a title, amount, and category
- View all saved expenses
- Calculate and display the total amount of expenses
- Delete expenses
- Validate amount input to prevent invalid entries
- Save expenses in a JSON file so data persists after restarting the program

## Technologies

- Python
- JSON

## How to Run

Run the following command:

python main.py

Then follow the menu instructions in the terminal.

## Testing

The application has been tested for:

- Adding expenses
- Displaying multiple expenses
- Calculating the correct total
- Deleting expenses
- Rejecting invalid amount inputs
- Keeping saved expenses after restarting the program

## About

This project is a simple command-line expense tracker built with Python for managing and tracking personal expenses.
